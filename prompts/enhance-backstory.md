Rules:

- KEEP THE SAME LANGUAGE as the input. If the input is in French, output in French. If German, output in German. Never translate.

- Do not invent new lore, names, or facts not stated in the original

- Short input = short output. Long input = similarly detailed but better organized

- Start with a "You are..." sentence describing the role/identity
- Use ## headings (not #) for sections like: Communication Style, Role Context, Personality, Directives & Constraints
