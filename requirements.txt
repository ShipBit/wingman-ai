# NVIDIA CUDA libraries for GPU-accelerated Parakeet (onnxruntime-gpu)
# These are bundled with PyInstaller to provide zero-config GPU support.
# CUDA 13, to match onnxruntime-gpu below: from 1.27.0 its CUDA provider links
# cublas64_13.dll / libcublas.so.13. The CUDA 13 wheels dropped the -cuNN suffix
# (only cuDNN keeps it) and all install into nvidia/cu13/, which onnxruntime's
# preload_dlls() knows. The majors must move together: a provider looking for
# CUDA 13 next to CUDA 12 libraries is still listed as available, fails to load
# and leaves Parakeet quietly on the CPU; 3.2.3 shipped exactly that.
# CUDA 13 needs NVIDIA driver 580 or newer and a Turing or newer GPU (GTX 16xx,
# RTX 20xx and up). Older setups get Parakeet on the CPU.
# Not available on macOS — CUDA is Windows/Linux only.

nvidia-cuda-runtime>=13.0,<14.0; sys_platform != 'darwin'
nvidia-cuda-nvrtc>=13.0,<14.0; sys_platform != 'darwin'
nvidia-cudnn-cu13>=9.13,<10.0; sys_platform != 'darwin'
# cuFFT is numbered 12 in CUDA 13. The provider needs it on both systems and
# cuRAND on Linux (libcurand.so.10).

nvidia-curand>=10.4,<11.0; sys_platform == 'linux'
