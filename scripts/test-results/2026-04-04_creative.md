## PROMPT 3: greeting-returning (with `<mem>` tags)

### ALL PRESETS FAIL on `<mem>` tag placement

Every single response across all 20 generations dumps the memory in a `<mem>` block as preamble, then writes the greeting separately. The model interprets "put `<mem>` around words from memory" as "quote the memory source in `<mem>` tags."

Example of what the model does (WRONG):
```
<mem>Memory from last session: User asked about trade routes near Hurston and mentioned they fly a Drake Cutlass Black.</mem>
"Hey kid, you still got that Drake Cutlass Black in your pocket?"
```

What we want (CORRECT):
```
"Hey kid, how's that <mem>Drake Cutlass Black</mem> holding up after those <mem>Hurston trade runs</mem>?"
```

**Verdict: This is a prompt problem, not a temperature problem.** Needs explicit correct/wrong examples.
